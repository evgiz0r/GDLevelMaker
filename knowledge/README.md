# knowledge/ -- what the user knows and thinks about Geometry Dash

Read this before making or judging a level. **Always read `opinions.md` and `critiques.md`.**

The user drops things here in any order (levels they like or hate, critiques, terms, Demon List
talk, screenshots). Rule: **the user's own words first** (quoted, dated), then what we make of it.
Their opinions and facts from the web are kept apart: every web fact has a source link and a date.

| file | what |
|---|---|
| `inbox/YYYY-MM-DD.md` | raw dumps, verbatim, in the order they came. Nothing is ever deleted here. |
| `opinions.md` | the user's taste: what they love, hate, care about (with quotes) |
| `critiques.md` | critiques of GDLM levels (ours) and what changed because of them -- **style/difficulty sessions must read** |
| `levels/<name>.md` | one level: facts (ID, creator, difficulty, source) / the user's opinion / what to learn |
| `creators/<name>.md` | creators the user mentions |
| `glossary.md` | GD terms as the user uses them |
| `demonlist.md` | Demon List facts (pointercrate etc.), dated and sourced |
| `eras.md` | eras and trends of GD level design |
