# Glossary -- GD terms

| term | meaning | source |
|---|---|---|
| prejump | a jump you must start in the middle of nothing, while what it is for is still far ahead; makes a level not sight-readable | playtest, 2026-11-22 |
| sight-readable | beatable on the first look: every press cued by something right in front of you | playtest, 2026-11-22 |
| triple | three spikes in a row (tightest common cube jump, ~46 ms window at 1x) | STYLE.md |
| practice mode | checkpoints mode; used to learn hard levels | common use |
| fake (pad/orb/portal) | looks like help but isn't, or kills; has to be learnt; bad at low tiers | wiki, Back On Track |
| teach, test, twist | introduce a mechanic alone, test it, then change it | GD Creator School |
| grayblock | build the gameplay in plain blocks before decorating | GD Creator School |
| map pack | RobTop's pick of user levels at one difficulty | Fandom wiki |
| Featured / Epic / Legendary / Mythic | rating tiers above a plain star rate, rising | GDBrowser |
